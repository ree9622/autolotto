## 📌 왜 '로또루틴'인가요?

"바쁜 일상 때문에 이번 주 로또 구매 마감 시간을 놓치셨나요?"  
"매주 수동으로 번호를 고르고 동행복권 사이트에 로그인해 결제하는 과정이 번거로우셨나요?"

**로또루틴(LottoRoutine)**은 동행복권(dhlottery.co.kr) 인터넷 로또 구매 및 당첨 번호 조회를 안전하고 편리하게 자동화해 주는 모바일 필수 앱입니다. 원하는 요일과 시간을 한 번만 설정해 두면 매주 자동으로 복권을 구매하고, 추첨 시간 직후 당첨 결과를 스마트폰 푸시 알림으로 알려드립니다.

## 📥 다운로드 및 간편 설치 방법

구글 플레이스토어 정책(도박 및 복권 관련 앱 제한)으로 인해 공식 GitHub Release를 통해 최신 APK 설치 파일을 무료로 직접 제공합니다.

1. **[최신 릴리스 다운로드 (v1.2.0)](https://github.com/ree9622/autolotto/releases/latest)** 페이지에서 `autolotto-1.2.0-universal.apk` 파일을 다운로드합니다.
2. 다운로드한 파일을 실행하여 설치를 시작합니다.
   - *'보안을 위해 출처를 알 수 없는 앱 설치가 차단되었습니다'* 알림이 뜨는 경우, 안내 팝업을 눌러 **'이 출처 허용'**을 체크해 주시면 정상 설치됩니다.
3. 앱을 실행하고 **설정 > 동행복권 계정 설정**에서 아이디/비밀번호를 입력합니다.
4. **번호 설정** 탭에서 구매할 번호를 지정하고 **자동 구매 스케줄**을 활성화하면 모든 준비가 완료됩니다!

> [!TIP]
> **💡 무인 자동 구매가 안정적으로 동작하려면?**  
> 안드로이드 OS의 배터리 절전 정책으로 인해 백그라운드 작업이 지연될 수 있습니다. 스마트폰 설정의 **'배터리 최적화 예외 앱'**에 로또루틴을 등록해 주시면 언제나 정시에 정확히 구매됩니다.

## ❓ 자주 묻는 질문 (FAQ)

### Q. 동행복권 사이트 예치금은 어떻게 충전하나요?
로또루틴 앱은 복권 구매를 자동화해 주는 도구로, 결제 원천인 예치금은 **[동행복권 공식 홈페이지](https://dhlottery.co.kr)**에 로그인하신 후 가상계좌(케이뱅크 등)를 통해 미리 충전해 두셔야 합니다.

### Q. 동행복권 인터넷 구매 한도가 있나요?
네, 동행복권 공식 정책상 인터넷 복권 구매는 **회차당 최대 5게임(5,000원)**까지 가능합니다. 로또루틴 역시 이 규정을 엄격히 준수하여 회차당 최대 5게임까지만 안전하게 구매하도록 설계되어 있습니다.

### Q. 제 동행복권 비밀번호가 개발자나 외부로 전송되나요?
**절대 아닙니다.** 로또루틴은 100% 오픈소스 프로젝트입니다. 비밀번호는 스마트폰의 Android Keystore를 통해 단말기 내부에만 암호화 저장되며, 로그인 요청 시에도 동행복권 공식 공개키(RSA PKCS#1)로 직접 암호화되어 동행복권 정식 서버(dhlottery.co.kr)로만 전송됩니다.

### Q. 앱 업데이트는 어떻게 하나요?
앱 내에 자체 인앱 업데이트 엔진이 탑재되어 있어, 새로운 버전이 출시되면 앱 실행 시 자동으로 감지하고 원탭으로 안전하게 최신 버전을 설치하실 수 있습니다.

## 🛠️ 기술 사양 및 개발 스택

- **언어**: Kotlin 2.2
- **UI 프레임워크**: Jetpack Compose (Material 3 Expressive 'Lucky Gloss' Theme)
- **백그라운드 아키텍처**: AlarmManager (정확 알람 자가 연쇄 스케줄링) + WorkManager (Expedited Worker)
- **네트워크 & 암호화**: OkHttp 4 (수동 쿠키 컨테이너 및 도메인 격리), Java Security RSA PKCS1, AndroidX Security Crypto (EncryptedSharedPreferences)
- **대상 플랫폼**: Android 12 이상 (API 레벨 31~36)
