# 구매 내역 조회와 통계

기존 구매 내역을 읽고 지출과 당첨금을 확인하는 화면입니다. 구매·충전·결제·예약 동작은 변경하지 않습니다.

- 처음에는 최근 3개월을 조회하며, `최근 1년 전체 불러오기`로 앱의 기존 조회 범위인 최근 1년을 읽습니다. 이는 무제한 과거 내역 조회를 뜻하지 않습니다.
- 각 기간의 마지막 빈 페이지까지 읽습니다. 서버가 요청한 100건보다 적게 응답해도 다음 페이지를 확인합니다. 반복 페이지·중복 주문·누락 응답·상세 조회 오류는 실패로 표시합니다.
- 전체·당첨만·추첨 대기를 선택할 수 있습니다. 필터는 목록에만 적용되고 통계는 불러온 전체 내역을 집계합니다.
- 총 구매액, 총 당첨금, 당첨금에서 구매액을 뺀 차액과 당첨·대기 회차를 표시합니다. 금액은 큰 당첨금도 처리하도록 64비트 정수로 계산합니다. 당첨금은 자료 제공값으로, 세금 차감 후 수령액을 보장하지 않습니다.
- 일부 조회만 성공하면 집계 기간과 부분 조회 상태를 표시합니다. 실패한 기간은 재시도하며 이미 읽은 금액을 버리지 않습니다. 새로고침도 기존 조회 범위를 유지합니다.
- 한국 날짜를 기준으로 서로 겹치지 않는 네 구간을 조회합니다. 새로고침을 시작할 때 날짜가 바뀌었다면 새 날짜까지 조회합니다. 계정 변경·로그아웃은 진행 중 요청과 이전 계정 화면을 초기화합니다.

## 접기·펼치기

기록 화면의 실제 가용 너비가 720단위 이상이고 높이가 480단위 이상이면 왼쪽에 통계·필터, 오른쪽에 목록을 배치합니다. 좁거나 낮은 창에서는 한 세로 목록으로 합칩니다. 화면 변경에 따른 필터와 목록 위치를 보존하며, 좁은 화면에서는 번호와 상태를 별도 줄에 놓습니다.

이번 대응 범위는 구매 내역 화면입니다. 반쯤 접힌 경첩 위치에 따른 분할이나 앱의 구매·충전 화면 변경은 포함하지 않습니다.

## 검증

자동 시험은 가짜 응답과 합성 내역만 사용합니다. 화면 시험은 계정·백그라운드 작업이 없는 별도 시험용 실행 환경에서 접힌 너비·펼친 너비·큰 글씨·필터·부분 실패·비로그인을 확인합니다. 실제 동행복권 계정으로 수집한 금액, 휴대전화에서 물리적으로 접고 펼치는 전환은 별도 확인 대상입니다.

```powershell
.\gradlew.bat --no-daemon --max-workers=2 :app:testDebugUnitTest :app:lintDebug
```

별도로 만든 시험용 가상 기기에서만 화면 검사를 실행합니다. 연결된 개인 기기를 대상으로 한 일괄 검사를 사용하지 않습니다.
