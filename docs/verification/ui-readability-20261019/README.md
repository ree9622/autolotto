# 시작 화면·홈 위계·접근성 검증

- 시작 화면: 현재 언어의 앱 이름과 본문 테마를 사용하며 로컬 설정 준비 뒤 즉시 이동한다. 강제 1.5초 대기를 제거했다.
- 홈: 최근 당첨 결과를 맨 위에 두고 초 단위 카운트다운을 한국 시간의 다음 추첨 날짜로 바꿨다.
- 어두운 화면: 남색·중립색 표면을 명시하고 주 버튼과 비활성 버튼의 글자색을 테마에서 가져온다.
- 접근성: 하단 메뉴에 탭 역할과 선택 상태를 제공한다. 공통 주 버튼은 표준 버튼의 역할·비활성 상태·누름 반응을 사용한다.

## 검증

`assembleDebug testDebugUnitTest lintDebug` 통과. `connectedDebugAndroidTest`는 기존 6개와 추가 5개를 포함해 총 11개 통과했다.
메뉴 선택 전환, 비활성 버튼의 클릭 차단, 밝고 어두운 화면의 주요 글자색 대비 4.5 이상, 시작 화면의 한국어 이름을 확인했다.
처음 실행은 가상 기기에 저장된 화면 크기 강제 설정 때문에 기존 접힘 전환 검사 1개가 실패했다. 화면 크기를 복원한 뒤 전체 11개가 통과했다.
